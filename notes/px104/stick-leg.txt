Nothing secret: no token, no key. The stick lane's INPUTS gains two
directories, burrow/ (tools/mkburrow's OUTDIR) and roots/ (tools/mkroots'),
read by tools/distribution-root and held by tests/distribution.

The leg, typed at the console with a network cable in the I225-V (px105's
stick-leg gives the lease first). Each line, and what it should show:

  cat /etc/resolv.conf                 the lease's name server
  den clone -q https://github.com/wolffe-lang/burrow.git /tmp/burrow-ro
                                       (a public repository: no token) exit 0, quietly;
                                       a name that resolves, a chain Mozilla's set verifies
  mkdir -p ~/.ssh && chmod 700 ~/.ssh && burrow-keygen -t ed25519 -f ~/.ssh/id_ed25519
  burrow-keygen -y -f ~/.ssh/id_ed25519
                                       the public line, to add to GitHub (a deploy key of a
                                       repository of yours, write access) if you want the ssh push
  printf 'Host github.com\n\tUserKnownHostsFile ~/.ssh/known_hosts /etc/ssh/ssh_known_hosts\n' > ~/.ssh/config
  ssh -T git@github.com                (the key not yet on GitHub) the refusal OpenSSH's ssh gives a
                                       keyless login, after GitHub's host key matched the pin

and then a push of your own, over either: `den push -q origin main` in a
clone of yours asks `Token: ` (no echo) unless DEN_HTTP_TOKEN is set; over
ssh it uses ~/.ssh/id_ed25519. What another answer means:
  den: wire: io, on a name          no name resolved: /etc/resolv.conf empty (no lease), or
                                    the server unreachable; a line in /etc/hosts is the fallback
  den: wire: Unsupported(TLS …)     the TLS client's own name for the refusal: issuer_mismatch
                                    (a root missing from the set, or a proxy in the way),
                                    expired or not_yet_valid (the clock: PAX reads the RTC as UTC)
  burrow: host_key_changed          something answered for github.com with another key: stop
  burrow: host_key_unknown          ~/.ssh/config does not name /etc/ssh/ssh_known_hosts
