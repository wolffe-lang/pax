Kernel changes:
  50f73421: TRACEME, a distinct tracing-stop state, legacy exec stop,
    CONT, GETSIGINFO, KILL, wait4/waitid including WNOWAIT/CLD_TRAPPED;
    vector 3 DPL 3; traced int3 -> SIGTRAP/SI_KERNEL. Existing kernel
    int3 behaviour is unchanged.
  c1de9a85: GETREGS/SETREGS, GETFPREGS, GETREGSET PRSTATUS/PRFPREG,
    PEEKUSER, debug-register POKEUSER and SINGLESTEP. The external
    selectors are Linux CS 0x33/SS 0x2b; setters translate to PAX's
    0x23/0x1b. No GDT renumbering. TracerPid is truthful.
    #DB remains DPL 0, uses IST4, and copies a user frame onto the
    thread's own kernel stack before it can be parked. Ordinary steps
    return si_code 2; stepped syscall completion returns the measured
    si_code 1. DR state is loaded per thread; reserved/GD bits cannot
    reach hardware. The thread record fills its existing 512-byte slot.
  d88960c2, b715dd44: traced memory words; /proc/<pid>/mem and
    task/<tid>/mem, with the shared FSCREDS rule at open; real-credential
    permission for TRACEME. Private borrowed file pages are copied;
    forced text writes do not grant the tracee write permission.
    Held proc-mem descriptors bind to an exec generation and CR3; they
    return EOF after the target ends or execs, not a later image's bytes.

The user cases use BIOS/KVM, tcg-core uses BIOS/TCG, and uefi-core uses
UEFI/KVM. Every matrix case also required no panic, init status 0 and
its process frame count restored. No skips. The errors case removes only
two kernel-narration lines, checked byte-for-byte first: the unknown
register set and unknown request, both 0x7fffffff. Nothing of the probe's
output is filtered. These rows complement, not replace, a future suite.

Light work used a two-CPU affinity and 6 GiB container cap. Measured busy
CPU averages for the boot legs were about 0.41–0.76; the small as launcher
build averaged 0.56. Kernel builds and the regression suites used a heavy
CPU block with both lock names. No Mac build/test ran.
