px60 prediction, before implementation or build measurements (2026-10-22).

P1. Alpine packaged static LLVM will link with the musl wolf driver after
selecting the matching LLVM major and its static system dependencies;
no wolf-lang source patch will be needed for M1.
P2. The stripped static wolf executable will be 80-160 MiB (point estimate
120 MiB); LLVM dominates the checked-machine executable.
P3. Across all requested commands wolf will add 8-15 syscall names over
px57 lupin (point estimate 11): process creation/wait, pipes, affinity,
randomness, and file-output operations. I predict no reached unsupported
PAX syscall on the no-link commands; native execution may expose flags.
P4. M2 will reach hello with musl binary CRT/libc and static LLVM lld,
using a cc-compatible wrapper. The likely wall if not is lld process/thread
or mapping behavior under PAX rather than wolf code generation. R-px60-1
remains a ruling for the orchestrator, not this lane.

These are predictions, not evidence. No static wolf, census, PAX run,
Linux comparison, or ISO has yet been produced by px60.
