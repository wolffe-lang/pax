BIOS, framebuffer and serial, no attached disk; run manually on nomad:
cd ~/pax-playground
qemu-system-x86_64 -machine q35 -cpu max -m 2048M -nic none \
  -cdrom pax-dev-pelt-friendly.iso -serial mon:stdio

Then type: set -o friendly -o suggest -o histsearch
Optional: PELT_COLORS='command=green:shadow=brblack+dim'

For UEFI add this read-only firmware argument to the same QEMU command:
-drive if=pflash,format=raw,unit=0,readonly=on,file=/opt/homebrew/share/qemu/edk2-x86_64-code.fd

Exit pelt to halt before closing QEMU. This ISO has a memory-backed tree;
there is no attached playground disk and edits do not persist across boots.
