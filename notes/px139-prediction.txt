px139: prediction, before changes

1. The existing warmed minimum-of-five probe remains unchanged in policy.
   Its boot line can retain all five read and write costs, the selected
   minima, the statistic, and the elapsed window without another probe or
   framebuffer read. A deterministic first slow read among four fast ones
   selects copy; five slow reads select redraw. fbread and fbwrite still
   bypass the probe. Rows first fail for absent sample reporting; a separate
   one-hunk single-sample plant fails the outlier row by name.
   The historical hosted logs contain only minima, not the probe window or
   individual costs: they cannot establish the duration or source of a
   sustained stall, nor whether a longer or spaced probe would change it.
   Compare the artifacts' command lines, framebuffer and firmware facts
   before proposing another policy. The serial-console mask and this
   reporting change must meet without masking overrides or genuine changes.

2. The unnecessary pointer interface's no-interrupt-IN diagnostic currently
   reaches the console. Recording it at informational level should retain
   it in the kernel log while the default console stays quiet. A QEMU
   nested-hub fixture and a descriptor fixture will identify what bytes
   justify the refusal; no claim identifies the physical switch's interface
   without its descriptors. The working keyboard and mouse remain usable.

3. A guarded UEFI-variable fallback requires runtime mappings and an x64
   firmware-call path, not just a spare CMOS range. Foreign CMOS bytes and
   foreign variable contents must remain unchanged. Every firmware write
   is opt-in with a named refusal; QEMU OVMF is the only write target here.
   The next boot should name the fallback and last stage. BIOS, absent
   services, disabled writes, invalid mappings and failed firmware calls
   must refuse plainly, with no early disk writes. A memory log cannot be
   promised across firmware memory training, clearing or reuse; no generic
   reserved range is guaranteed by this board's class alone.
