# extent.txt -- the code points PAX's console draws above U+00FF (gm01),
# one code point or an inclusive range a line, with where its glyphs come
# from. tools/mkfont builds boot/font.S's table from this file and
# tools/screen-ref draws the same set; any other code point at or above
# U+0100 is drawn as `?`.
#
#   generated  tools/mkfont's functions (braille: the code point's eight
#              dot bits as a 2x4 matrix of two-pixel dots; the block
#              elements: filled rectangles), each held to Spleen's own
#              glyph bit for bit at build time (refused by name if not)
#   spleen     font/spleen-8x16.bdf, as Spleen 2.2.0 draws it (the
#              shades are its 25/50/75 % dithers)
#   pax        font/pax-extra.bdf, PAX's own rows (drawn by gm01)
#
# The set is the union of the wolf games' docs/GLYPHS.md lists
# (font/games-glyphs.txt), widened to whole Unicode blocks where a
# function draws the block: all 256 braille patterns and all 32 block
# elements. px125 adds what a terminal multiplexer's client draws: the
# whole box-drawing block (U+2500-U+257F: a split's tees and crosses,
# heavy, double and rounded lines), the four arrows (U+2190-U+2193, a key
# hint bar's) and the powerline separators (U+E0A0-U+E0A2,
# U+E0B0-U+E0B3), every one Spleen's own glyph.
