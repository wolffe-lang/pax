# tools/screen-ref draws the same set; any other code point at or above
# U+0100 is drawn as `?`.

#   spleen     font/spleen-8x16.bdf, as Spleen 2.2.0 draws it (the
#              shades are its 25/50/75 % dithers)

# The set is the union of the wolf games' docs/GLYPHS.md lists
